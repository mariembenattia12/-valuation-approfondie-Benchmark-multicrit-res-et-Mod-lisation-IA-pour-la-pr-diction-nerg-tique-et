# Notebooks

Créer les notebooks dans cet ordre :

1. `01_exploration.ipynb` — inspection des fichiers et des colonnes ;
2. `02_pretraitement.ipynb` — nettoyage, valeurs manquantes et variables ;
3. `03_visualisation.ipynb` — tendances, profils horaires et couverture temporelle ;
4. `04_parametres_consommation.ipynb` — extraction des indicateurs de consommation et de comportement ;
5. `05_structuration_fenetres.ipynb` — fenêtres glissantes de 672 pas et 11 variables ;
6. `06_benchmark.ipynb` — entraînement et comparaison des modèles ;
   `phase2_kaggle_benchmark.ipynb` — benchmark Kaggle complet : SARIMAX, baselines, Random Forest, SVR, XGBoost/LightGBM et réseaux multi-sorties ;
7. `07_facturation.ipynb` — calcul de la facture réelle et prédite.
